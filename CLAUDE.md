# go-mastery-task-tracker

Go CLI (`task-cli`) for the roadmap.sh Task Tracker project: add, update, delete, mark and list tasks stored in a JSON file in the current directory. Standard library only.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues for stonalampa/go-mastery-task-tracker (via `gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
